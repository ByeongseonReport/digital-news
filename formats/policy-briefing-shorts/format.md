# 정책브리핑 쇼츠 제작 규격

상태: 2026-09-30 이식 정본

## 용도와 산출물

대한민국 정책브리핑의 정책뉴스·보도자료를 국민 생활 관점에서 풀어 쓰는 낭독 대본이다.
한 건의 산출물은 **후킹 헤드라인 + 쇼츠 대본 + 커뮤니티 게시물 + 출처**다. 영상 지시,
촬영과 편집은 범위에 포함하지 않는다.

## 길이

- 낭독 90~120초, 2분을 넘기지 않는다.
- 쇼츠 대본 본문은 공백 포함 850~1,100자, 13~17개의 짧은 문단을 기준으로 한다.
- 후킹 헤드라인, 커뮤니티 게시물과 출처는 낭독 자수에서 제외한다.
- 실제 낭독 속도는 초당 7.9~8.6자, 중앙값 8.3자였다. 숫자·법령명이 많으면 더
  느려지므로 최종본은 낭독으로 확인한다.
- 분량은 반복이나 행정 수식어가 아니라 대상, 변화, 수치, 절차, 예외와 논란으로 채운다.

## 소재와 조사

1. 기본 원자료는 `korea.kr`의 정책뉴스와 보도자료다. 사용자가 주제를 주면 해당
   원자료를 먼저 찾는다.
2. 여러 정책을 묶은 발표에서는 생활 영향과 화제성이 가장 큰 이슈 하나만 중심으로
   삼는다. 제목과 본문의 무게중심을 일치시킨다.
3. 보강 자료는 원칙적으로 작성일 기준 최근 1주일 이내 자료를 쓴다. 오래된 자료는
   제도의 배경·연혁에만 쓰고 날짜를 밝힌다.
4. 정부 설명을 그대로 전달하지 않는다. 적용 대상, 예외, 비용, 이해관계자 반응이나
   실제 집행상의 빈틈을 확인한다. 관련 논란이 있으면 대본의 한 구간으로 다룬다.
5. 시행일, 대상, 금액, 신청 절차와 처분 기준은 원자료로 확인하고 독립 출처로 교차
   확인한다. 확인하지 못한 처리 결과는 추정하지 않는다.

## 구성

구간은 문단 수가 아니라 기능이다. 소재에 따라 합칠 수 있지만 순서는 유지한다.

| 구간 | 역할 | 권장 자수 |
|---|---|---:|
| 1. 생활 훅 | 시청자에게 무엇이 달라지는지 첫 문장에 제시 | 80~120자 |
| 2. 정책 핵심 | 대상·시행일·금지 또는 지원 내용을 일상어로 설명 | 170~230자 |
| 3. 작동 방식 | 수치·절차·대표 사례로 실제 적용을 보여 줌 | 250~320자 |
| 4. 예외와 논란 | 허용 범위, 사각지대, 반론, 이해관계자 반응 | 180~260자 |
| 5. 실용 결말 | 신청법·처분·다음 조치·남은 쟁점 중 가장 중요한 것 | 120~180자 |

첫 문장은 기관명이나 `정부가 발표했습니다`가 아니라 시청자 이해관계로 연다. 궁금증만
던지고 핵심을 미루지 말고, 변화와 대상을 첫 문장 안에 같이 준다. 헤드라인이 이미 준
결론을 첫 문장에서 그대로 반복하지 않는다.

## 문체

- 기본은 정확한 존댓말 낭독체다. `~습니다`를 뼈대로 삼되 연결부에는 `~인데요`,
  `~고요`, `~죠`를 제한적으로 섞어 읽기 쉽게 한다.
- 한 문장에는 정보 하나만 둔다. 법령명과 행정용어는 먼저 일상어로 풀고 필요할 때만
  공식 명칭을 붙인다.
- 기관의 자화자찬, 추진 의지, 기대 효과 같은 홍보 문구는 사실이나 수치가 없으면
  덜어낸다.
- 지상파 수준으로 절제한다. 낚시성 제목, 과장형 수식어와 근거 없는 단정은 쓰지 않는다.
- 결말은 추상적 교훈으로 닫지 않는다. 누가 언제부터 무엇을 해야 하는지, 제도가 실제로
  작동할지는 어디에서 판가름 나는지를 말한다.

## 커뮤니티 게시물

- 헤드라인은 굵은 글씨 한 줄로 둔다.
- 본문은 하이픈 불릿 4~9개, 한 줄에 정보 하나로 쓴다.
- 낭독 대본을 문장째 복사하지 말고 대상·시행일·금액·절차·예외를 빠르게 찾을 수 있게
  압축한다.
- 출처에는 제목, 게시일, 직접 URL과 해당 출처가 뒷받침한 사실을 적는다.

## 최종 검사

- [ ] 낭독 90~120초, 공백 포함 850~1,100자
- [ ] 문단 13~17개
- [ ] 첫 문장이 기관 발표가 아니라 생활 변화와 대상을 말함
- [ ] 헤드라인과 첫 문장이 같은 정보를 반복하지 않음
- [ ] 중심 이슈 하나만 설명함
- [ ] 시행일·대상·금액·절차의 직접 근거가 있음
- [ ] 예외·논란·사각지대 중 하나를 다룸
- [ ] 행정 자화자찬과 중복 수식을 제거함
- [ ] 결말이 실제 적용이나 남은 쟁점을 말함
